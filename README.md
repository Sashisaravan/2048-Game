# 🎮 2048 Game

A simple and interactive **2048 Game** built using **React.js** and **Material UI**.

## 🚀 Features

- 🎯 Classic 2048 gameplay
- ⌨️ Keyboard arrow controls
- 🔄 Restart game option
- 🏆 Win and Game Over detection
- 🔊 Game sound effects
- 📱 Responsive UI
- 🎨 Clean and modern design

## 🛠️ Tech Stack

- React.js
- JavaScript
- Material UI (MUI)
- Vite
- CSS
